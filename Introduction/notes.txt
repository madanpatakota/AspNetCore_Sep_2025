📌 What is HttpContext?
-----------------------
In ASP.NET Core, HttpContext is a special context object for web requests.
It contains everything about the current HTTP request and the response that will be sent back.


🔎 What does HttpContext include?
- Request → URL, headers, query params, body, cookies
- Response → status code, headers, body, cookies
- User → identity, roles, claims
- Items → custom data you can pass along during request
